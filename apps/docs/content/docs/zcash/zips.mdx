## The standard amounts

ZIP 318's denominations, as Mitoshi uses them: seven sizes from 0.01 to 1 ZEC. A funding is always exactly one of
them, and the leak meter blocks any other amount. Amounts above 1 ZEC are not split; a wallet holds one size.

## The timing rules

| Rule | Value | Code |
| --- | --- | --- |
| A funding you asked for | starts at a random moment 20 s to 3 min later (uniform) | `fundingTime`, `packages/engine/src/schedule.ts` |
| A keep-ready refill | waits an exponential delay, 90 min on average, between 20 s and 12 h (the first wallet after the switch goes on starts like one you asked for) | `refillTime`, same file; `setKeepReady`, `apps/web/src/features/private-wallets/jobs.ts` |
| A funding due while the app was closed | gets a new random start instead of going out when the app opens | `retimed`, same file |
| After a broadcast | no sync for a random 1 to 10 min | `SEND_QUIET_MIN_MS`, `apps/web/src/constants.ts` |

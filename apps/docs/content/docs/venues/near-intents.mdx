## Routes

| Venue | Funding (ZEC →) | Trip home (→ ZEC) | Confidential |
| --- | --- | --- | --- |
| Polymarket and Perps | USDC on Polygon, else Arbitrum, else Base, to the wallet's Polymarket bridge address | USDC on Polygon from the bridge → ZEC | Funding yes; trip home no (flexible-input quote) |
| Hyperliquid | USDC on HyperCore | HyperCore USDC → ZEC | Both |
| Solana | SOL | SOL → ZEC | Both |

A funding is always one of the seven [standard sizes](/docs/zcash/zips#the-standard-amounts). The swap settings: exact
input, 1% slippage, a two-hour deadline.

## The quote check

<Shot src="/shots/wide/fund-route.webp" alt="The New private wallet sheet with its details open: a new wallet gets ≈ 61.4258 USDC (≈ $61.40, about 8 min), the network fee 0.00015 ZEC, Mitoshi fee none, and the route NEAR Intents · confidential." caption="The funding sheet asks NEAR Intents for a price over Oblivious HTTP and shows the route." />

Before any ZEC moves, Mitoshi checks each quote:

1. **The signature.** 1Click signs each quote with ed25519; Mitoshi verifies it against 1Click's published key, pinned
   in `packages/rails/src/constants.ts`.
2. **The terms.** The quote must echo what was asked: the assets, the amount, the recipient and the refund address.
   A live quote must carry a deposit address.
3. **The record.** The whole signed quote is saved in the encrypted vault before the payment, so a closed tab can find
   the swap again and any dispute can be settled.

Then one shielded payment of exactly the wallet's size goes to the deposit address, and its transaction id is sent to
1Click. Mitoshi follows the swap every 15 seconds while the app is open.

## Confidential mode

Confidential mode means NEAR doesn't publish which deposit paid which payout. It needs NEAR's partner key, which the
gateway adds to 1Click calls; the browser never sees it. Mitoshi asks for it on every quote except Polymarket's trip
home. If 1Click refuses a confidential quote (HTTP 401), the app uses public quotes for the rest of the session, and the
route line drops "confidential". The app shows the mode it asked for; it doesn't read the mode back from the quote.

## Refunds

| Swap | If NEAR can't complete it |
| --- | --- |
| A funding | The ZEC comes back to a fresh shielded address made for this swap; the wallet shows **Refunded** |
| A trip home | The money comes back to the venue wallet. On Hyperliquid and Solana, send it home again; on Polymarket it returns as USDC on Polygon in the Deposit Wallet, which Send home doesn't pick up yet |

## Fees

Mitoshi adds no fee of its own. A 0.2% funding fee is built in but switched off: no fee recipient is set
(`APP_FEE_RECIPIENT` is `null`), so Mitoshi sends no app fee with its quotes, and the funding sheet shows "Mitoshi fee:
none". You pay the swap spread and NEAR's own
fees, which are part of the quote.

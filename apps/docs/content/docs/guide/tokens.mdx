Search by name or mint. Each row shows **Price**, **Change**, **Market cap** and **Liquidity**; open one for its page.

## A token

<Screen name="token" alt="A Solana token page on mitoshi.xyz with its price and candles; on desktop the swap ticket sits beside the chart, on a phone BUY and SELL open it." caption="The token page: price, chart (5m to 1d, candles or line) and the ticket." />

| Control | Options |
| --- | --- |
| Side | **Buy** with SOL, **Sell** for SOL |
| Amount | **0.05 0.1 0.25 0.5** SOL to buy; **25% 50% All** to sell |
| Shown | **You get**, **Impact**, **Route** |
| Button | **Buy SYM** / **Sell SYM**; **Fund a private wallet** without one |
| **Sell all and send home** | Sells every token back to SOL and starts the trip home (when a ready or trading wallet exists) |

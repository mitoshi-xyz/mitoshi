## Fees

| What | Charged by | How much |
| --- | --- | --- |
| Trading | Mitoshi | **None added.** No fee and no builder code on any order |
| Funding | Mitoshi | **None added.** A 0.2% funding fee exists in the code but is off: no fee recipient is set (`APP_FEE_RECIPIENT` is `null`), so Mitoshi's quotes carry no app fee, and the funding sheet shows "Mitoshi fee: none" |
| Venue fees | Polymarket, Hyperliquid, Jupiter | Each venue's own; the perps ticket shows its fee before you trade |
| The swaps | NEAR Intents | The spread and NEAR's fees, inside the quote you see before you fund |
| Zcash network fee | Zcash miners | The ZIP 317 fee; the funding sheet reserves 0.00015 ZEC for it |
| Polymarket bridge | Polymarket's bridge | Shown in the funding sheet for Polymarket |

## Timing

| Step | Typical time | From |
| --- | --- | --- |
| A new wallet starts funding | 20 s to 3 min after you ask, at random | Mitoshi's scheduler |
| A keep-ready wallet starts funding | After a random wait, 90 min on average, at most 12 h (the first one too) | Mitoshi's scheduler |
| Funding: ZEC in, venue asset out | About 8 minutes | 1Click's estimate (465 s in a quote of 2026-10-22; "about 8 min" in the funding sheet on 2026-10-23) |
| Polymarket credit: USDC to pUSD | Not estimated; the wallet turns Ready when the bridge reports it (its fee is in the sheet) | Polymarket's bridge |
| A deposit shows up | One block, about 75 s on mainnet | Zcash |
| A deposit can be spent | 10 confirmations, about 12–13 min (your own change: 3) | librustzcash's default confirmation policy |
| The wallet checks for blocks | Every 30 s; not for 1–10 min after a send | Mitoshi's wallet |
| Rest after a public arrival (an exchange, or a trip home) | 2 to 6 h, per note | Mitoshi's rest rules |

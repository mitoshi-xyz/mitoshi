[mitoshi.xyz/status](https://mitoshi.xyz/status) checks each part over the same path the app uses, and says what each
one sees:

| Row | What it sees | Its check |
| --- | --- | --- |
| Your browser | Everything, encrypted on this device | this device |
| Mitoshi relay · Cloudflare | Your IP address, never what you ask | the live feed: live, connecting or reconnecting |
| Mitoshi gateway · Ireland | What is asked, never who asks | a sealed round trip, in ms |
| NEAR Intents · 1Click | Each swap: a standard ZEC amount in, a fresh wallet out | ms |
| Jupiter · Solana | A fresh Solana wallet's swaps, from the gateway's address | ms |
| Polymarket | Market reads from the gateway's address | ms |
| Polymarket Perps | A fresh wallet's Perps orders, signed by its own proxy key | ms |
| Hyperliquid | A fresh account's orders, from the gateway's address | ms |
| Zcash light server | Requests for blocks from the gateway; your notes are decrypted only in your browser | the latest block once a wallet is open |

The six service rows can each be checked again. A row over 2.5 s says "slow"; one that fails says "not answering". On
screens 640 px and wider, the chip at the top (Private relay · live, Connecting…, Reconnecting…) opens this page.

## From your browser

<Steps>
<Step>

**Only one host.** Open [mitoshi.xyz](https://mitoshi.xyz) with DevTools → Network and use the app. Every request goes
to `mitoshi.xyz`: calls about you are `POST /relay/ohttp` with `content-type: message/ohttp-req`, live prices are
WebSockets on `/relay/live/*`, list pictures are `GET /relay/img`, and fonts and scripts come from the same origin.

</Step>
<Step>

**Sealed bodies.** Click any `/relay/ohttp` request: its payload is ciphertext, not JSON.

</Step>
<Step>

**What a copy trader sees.** Every private wallet has a "What the public sees" view, read live from the venue's own
public data over Oblivious HTTP.

</Step>
</Steps>

## From a terminal

The gateway's key as the gateway serves it, and as the app pins it. They must match, or the relay could read your
requests:

```bash
curl -s https://mitoshi-gateway.vercel.app/ohttp-keys | base64
```

```bash
grep GATEWAY_KEY_CONFIG packages/net/src/constants.ts
```

Both print `ACkBACAV5em/Jd6iTp3ZtsO+Q8c6/nXzvtWg04Rq5UUC675KYwAEAAEAAQ==` (checked 2026-10-23).

The page headers: a CSP with script hashes and no `unsafe-inline` for scripts, and `no-transform`, so Cloudflare can't
add a script on the way:

```bash
curl -sI https://mitoshi.xyz/ | grep -iE 'content-security-policy|cache-control'
```

The gateway refuses anything that doesn't come through the relay:

```bash
curl -s -o /dev/null -w '%{http_code}\n' -X POST https://mitoshi-gateway.vercel.app/ohttp
```

It prints `401`. The allowlist, every host and path the gateway will call for you, is
[`services/gateway/src/constants.ts`](https://github.com/mitoshi-xyz/mitoshi/blob/main/services/gateway/src/constants.ts).

title: Troubleshooting
description: What to do when a deposit, a funding or a trip home seems stuck.
---

Start at [mitoshi.xyz/status](https://mitoshi.xyz/status): it shows whether the gateway, NEAR Intents, each venue and
the Zcash light server are answering.

| What you see | Why | What to do |
| --- | --- | --- |
| A deposit says **resting 2–6 h** | It came from a public (transparent) address | Wait; it can fund wallets once rested. Deposit from a shielded wallet next time |
| The balance has not moved | The wallet syncs every 30 s, and pauses 1–10 min after each send | Wait a minute; a send is followed by a quiet window on purpose |
| A funding is **preparing** for minutes | It starts at a random moment, 20 s to 3 min after you ask | Wait. A keep-ready refill can wait hours (90 min on average, 12 h at most) |
| The leak meter is **red** on a funding | The size is not standard, or it would spend resting ZEC | Pick a standard size, or wait for the rest to end |
| The leak meter is **amber** on a withdrawal | The amount is close to a recent payout, or it is within 2 h of one | Send to a shielded address, or wait and change the amount |
| "Private wallets are funded through NEAR Intents, which only takes mainnet ZEC." | The app is on testnet | Use mitoshi.xyz (mainnet) |
| A funding shows **refunded** | NEAR could not complete the swap | The ZEC went to a fresh shielded address in your balance |
| A funding shows **failed** | A step failed before anything was sent | Try again; it waits for a new random start |
| A trip home was **refunded** | NEAR could not complete the swap home | The money is back in the venue wallet; send it home again |
| Something is left in a retired wallet | It is smaller than the trip home would cost | It stays as [dust](/private-wallets#dust) |
| A wallet is missing after a restore from words | The scan that starts after a restore checks one address every 3–9 s, so it takes a while | Let it finish, or run Settings → **Find my wallets** again. A backup file restores the list at once |
| Mitoshi asks for a passphrase | The passphrase lock is on | Enter it. There is no reset: without it, restore from the 24 words |

If the tab closes while a wallet is being set up, it finishes the next time Mitoshi opens.

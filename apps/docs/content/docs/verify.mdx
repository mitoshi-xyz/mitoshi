## Check it from your browser

<Steps>
<Step>

**Only one host.** Open [mitoshi.xyz](https://mitoshi.xyz) with DevTools → Network, and use the app. Every request
goes to `mitoshi.xyz`: calls about you are `POST /relay/ohttp` with `content-type: message/ohttp-req`, live prices
are WebSockets on `/relay/live/*`, and list pictures are `GET /relay/img`. Fonts and scripts come from the same origin.

</Step>
<Step>

**Sealed bodies.** Click any `/relay/ohttp` request: the payload is ciphertext, not JSON.

</Step>
<Step>

**Confidential swaps.** Open **Privacy** in the app: it says whether NEAR's confidential mode is on for your swaps.
The Fund screen adds "confidential" to the quote line when it is.

</Step>
</Steps>

## Check it from a terminal

The gateway's key, as pinned in the app (`packages/net/src/constants.ts`), and as the gateway serves it. The two must
match, or the relay could read your requests:

```bash
curl -s https://mitoshi-gateway.vercel.app/ohttp-keys | base64
```

```bash
grep GATEWAY_KEY_CONFIG packages/net/src/constants.ts
```

The page headers: a CSP with script hashes and no `unsafe-inline` for scripts, and `no-transform` so Cloudflare cannot
add a script:

```bash
curl -sI https://mitoshi.xyz/ | grep -iE 'content-security-policy|cache-control'
```

The gateway's allowlist, every host and path it will call for you: `services/gateway/src/constants.ts`.

The tests:

```bash
pnpm install && pnpm test
```
